# API 복원 및 저비용 모델 후보 — 2026-09-06

기본값은 기존 `gemini-2.5-flash`로 복원했다. `LLM_PROVIDER=gemini`,
`GEMINI_MODEL_NAME`으로 선택하며 로컬 `.env`의 기존 키를 사용한다.
로컬 모델용 카드와 prompt compiler를 거치지 않고 기존 작문 템플릿 전체와 선택 페르소나를 보낸다.
수집 보호·DB·수동 검토·JSON 검증·호출 예산은 유지한다.

## 후보

USD / 100만 텍스트 토큰, 일반 동기 호출·캐시 미적중 기준이다.
1,000건 비용은 매번 입력 8,000 + 출력 400토큰인 생성 호출만 가정했다.
분석·Judge·재시도·추론 토큰·검색 도구·세금은 별도이며 실제 토큰 수에 따라 달라진다.

| 모델 | 입력 | 출력 | 1,000건 예시 | 이번 확인 / 판단 |
|---|---:|---:|---:|---|
| Gemini 3.1 Flash-Lite | $0.25 | $1.50 | $2.60 | 동일 전체 프롬프트 초안 1건 성공. 비용 절감 비교 1순위 |
| Gemini 2.5 Flash | $0.30 | $2.50 | $3.40 | 기존 기본값 복원. 실제 JSON·초안 확인 |
| GPT-4.1 mini | $0.40 | $1.60 | $3.84 | 지시 이행·구조화 출력 비교 후보. 이 앱용 OpenAI 어댑터·키·실측은 미구현/미검증 |
| DeepSeek V4 Flash | $0.22–0.44 | $0.66–1.32 | $2.02–4.05 | 비혼잡/혼잡 시간에 따라 가격이 변함. 어댑터·키·실측은 미구현/미검증 |

Google 공식 [가격](https://ai.google.dev/gemini-api/docs/pricing),
[종료 일정](https://ai.google.dev/gemini-api/docs/deprecations),
OpenAI 공식 [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini),
DeepSeek 공식 [가격](https://api-docs.deepseek.com/quick_start/pricing/)을 확인했다.
JSON 지원은 한국어 문체·페르소나 품질이나 무중단 운영의 보장이 아니다.

`gemini-2.5-flash-lite`는 공식 표상 $0.10/$0.40으로 더 저렴하지만 이번 키·generateContent 경로에서 HTTP 404를 반환했다.
서비스 전체 종료라고 단정할 수 없으며, 현재 환경에서 바로 사용할 후보에서는 제외한다.

## 실제 연결 검증

- `gemini-2.5-flash` 최소 JSON: 1.59초, 입력 14 / 출력 5토큰.
- `gemini-2.5-flash` 합성 게시판 분석: 3.98초, 입력 3,153 / 출력 450토큰. A/B/C 주제와 분석 결과 파싱 성공.
- 기존 `GhostBrain.generate_post`, 합성 토성 관찰, `neutral` 페르소나, 최근 게시글/DB 예시 미사용:
  - 2.5 Flash: 2.70초, 입력 6,829 / 출력 49토큰, 파싱 성공.
  - 3.1 Flash-Lite: 2.45초, 입력 6,829 / 출력 91토큰, 파싱 성공.
- 3.1 표본: `토성 고리 그림자 선명하게 찍혔네` / `행성 표면 가로지르는 라인 보니까 묘함`.
- '선명하게'는 합성 입력에 명시되지 않은 수식이다. 한 건 성공을 품질 합격으로 승격하지 않는다.
- 실제 게시판 수집·로그인·게시·댓글 등록은 수행하지 않았다. 위 지연은 단일 표본으로 성능 순위가 아니다.

## 운영과 재검증

현재 UI 기본 예산은 실행당 120회다. 예산은 비용 달러 상한이 아니라 호출 수 상한이다.
API 화면의 '설정됨'은 키가 존재한다는 의미이며, 화면을 다시 그릴 때 과금 요청을 하지 않는다.
401/403/404/429, 네트워크 시간 초과, 차단·빈 응답·잘림을 구분하며 업체나 모델을 자동 전환하지 않는다.
API 오류 원문에는 키가 포함될 수 있으므로 HTTP 상태와 고정 설명만 진단에 남긴다.

`RUN_GEMINI_LIVE=1`로 `python -m pytest tests/integration/test_gemini_live.py -q`를 실행하면
실제 과금 가능성이 있는 최소 합성 JSON 검증을 한다. 일반 pytest에서는 건너뛴다.
다음 선택은 2.5 Flash와 3.1 Flash-Lite에 같은 페르소나·입력 묶음을 주고 원고 품질을 비교하는 것이다.
