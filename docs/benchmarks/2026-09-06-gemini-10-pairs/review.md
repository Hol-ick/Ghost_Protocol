# 검토 메모

20건은 모두 API 응답·앱 파싱에 성공했다. 각 페르소나의 두 요청은 전체 request 해시가 같고, 실제 전송 프롬프트에 톤 지시와 심화 프로필의 어휘 스타일이 포함됐음을 20건 모두 확인했다. 이것은 전달 검증이지 지시 준수 100% 판정이 아니다.

## 원문에서 확인한 주의점

- 댓글 대상 입력이 빈 배열인데 3.1은 10/10건(댓글 11개), 2.5는 1/10건(댓글 1개)에서 임의 post_no 1 또는 2와 댓글을 반환했다. 이 부가 출력은 JSON 원본에 보존했고 비용에도 포함했다. 원고 본문 20개와 별개이며 실제 댓글 등록은 없다. 현재 파서가 이를 받아들였으므로 정상 파싱은 게시 가능 판정이 아니다. 특히 3.1의 09번 댓글은 실제 경험처럼 '나도 방금 렌즈 닦고 있었는데'를 만들어냈다.
- 02 neutral: 두 모델 모두 입력에 없는 '진하게/선명하게'를 붙였다. 3.1은 길이·각도 설명도 추가했다.
- 05 aggro: 두 모델 모두 질문형 제목을 사용했다. 현재 프로필의 '질문 낚시보다 짧은 반대 주장이나 비꼼' 지시를 충분히 따르지 않았다. 고배율이면 항상 흐려진다는 일반화도 주의해야 한다.
- 06 monologue: 3.1 제목 '보임?'은 답을 요구하지 않는 혼잣말 지시와 어긋난다.
- 09 doomer: 2.5는 질문 대신 결과를 예상하라는 지시에도 질문형 제목을 썼다. 3.1은 원본에 없는 이동 속도와 '30분 안에'라는 구체 시간을 만들어냈다.
- 일부 제목은 한 줄 반응치고 길다. 특히 3.1의 07·09번은 짧은 제목 목표와 거리가 있다.

## 비용 해석

- 2.5 Flash: 입력 68,276, 출력 583, 캐시 입력 1,906, 추론 출력 0 → $0.02142568.
- 3.1 Flash-Lite: 입력 68,276, 출력 1,062, 캐시 입력 0, 추론 출력 0 → $0.01866200.
- 합계 $0.04008768. 이 실험에서는 3.1이 약 12.9% 저렴했다. 캐시 미적중 가정의 가격표 비교와 실제 절감률은 다르다.
- 이 비용은 이번 원고 생성 호출 20회만 포함한다. 이전 API 복원 테스트·게시판 분석·별도 Judge 호출은 포함하지 않는다. 이번 실험에서는 재시도·추가 분석·Judge API 호출을 하지 않았다.
- 실제 요금제·무료 구간·크레딧·세금·청구서는 확인하지 않았다. 금액은 API 사용량과 공식 일반 유료 단가 기준 계산액이다.

## 판단

두 모델을 후보로 유지한다. 비용 차이는 작고, 양쪽 모두 짧은 문장 생성은 가능하지만 질문형 습관과 근거 없는 수식은 남아 있다. 기본 모델은 변경하지 않았다. 사람이 10쌍을 읽고 선호와 사실성을 비교한 뒤 선택하는 것이 다음 행동이다.
