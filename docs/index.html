Core System

운영자가 볼 수 있어야 오래 달릴 수 있습니다.

01

Board Intelligence

원본 글, 댓글 세트, 글 간격, 브리핑, 작문 지시를 한 번에 검토 가능한 패키지로 묶습니다.

02

Rehearsal Loop

사이클마다 주제 이동과 생성 결과를 비교해 프롬프트와 페르소나의 드리프트를 확인합니다.

03

Stability Policy

쿼터, 빈 수집, 반복 실패, 발행 실패, 댓글 피드백을 감지하고 무한 실행을 안전하게 멈춥니다.

Workflow

수집부터 운영 리포트까지.

  1. Collect게시판 원본 세트와 리듬을 수집합니다.
  2. Brief현재 흐름과 안전한 작문 지시를 분리합니다.
  3. Rehearse다중 사이클로 문체와 주제 수렴을 점검합니다.
  4. Operate로그와 안정성 진단을 보고 수동 또는 자동으로 멈춥니다.
