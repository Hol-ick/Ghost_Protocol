[Task]
제공된 텍스트 데이터를 바탕으로 현재 갤러리에서 유저들이 무엇에 꽂혀 있는지 민심과 떡밥을 분석해라.

*필드별 작성 가이드 (매우 중요)*
1. ai_analysis (AI 브리핑):
   - 갤러리의 메인 떡밥을 커뮤니티 현지인 시각으로 냉소적으로 요약해라.
   - [핵심 차단 룰] '특정 유저의 도배', '갤러리 리젠율' 같은 시스템/메타적인 현상 분석은 절대 금지.
   - 🚨 [네임드/친목 배제] 특정 유저의 닉네임이나 저격 떡밥은 철저히 무시해라.
   - 🚨 [대주제 편식 방지] 특정 샵(예: 티짐)이나 단일 가십 키워드 하나에만 꽂혀서 분석하지 마라. 해당 갤러리의 '본질적인 대주제($gallery_id의 핵심 카테고리, 예: 보드게임, 룰, 기물, 덱 성능 등)'를 아우르는 폭넓은 떡밥을 골고루 짚어줘라.
   - 🚨 [온도 클리핑] ai_analysis 자체는 극단 언어 사용 금지. 갤러리가 아무리 과격해도 '각 나옴', '분위기 심상찮음', '뜨겁긴 함' 수준까지만. '폭발', '개전', '대혼란', '위기', '초읽기' 같은 극단 표현은 삭제해라.
   - 🚨 [공문서체 차단] '~에 대한 우려', '논의가 활발하며', '전반적으로', '파장에 대한 관심', '~에 따른', '~에 있어', '~에 관한' 같은 기사/공문서 어투 완전 금지. 짧고 냉소적인 현지인 말투로.
   - 🚨 [길이 제한] ai_analysis는 80자 이내 1~2문장으로. 넘어가면 즉시 잘라라.

2. summary (포스팅 씨앗 떡밥 풀): 
   - [초강력 형태 통제] **절대 완성된 문장으로 작성하지 마라. 문장 부호(마침표, 쉼표 등)와 서술어('~합니다', '~입니다', '~음', '~다') 사용을 엄격히 금지한다.**
   - 🚨 [다중 키워드 뷔페 강제] 갤러리($gallery_id)에서 현재 실제로 논의되는 서로 다른 구체적인 메인 떡밥 3~4개를 추출해, 오직 '명사형 단어/구(Phrase)' 단위로 쪼갠 뒤 '슬래시(/)'로만 나열해라. 단일 주제만 던지는 것은 절대 금지.
   - 🚨 [target_noun 분산 강제] 각 슬래시 구분 단위에 서로 다른 고유명사(인물명/팀명/사건명/수치/제품명)가 하나씩 들어가야 한다. 동일한 고유명사가 2개 이상 슬래시 단위에 중복 등장하면 즉시 폐기하고 다시 써라.
   - [메타 발언 및 인물 저격 절대 금지] 갤러리의 리젠율, 유저 간의 싸움, 특정 유저의 닉네임은 단 한 글자도 적지 마라.
   - 예시(좋음 - 게임갤): "신규 패치 밸런스 / A캐릭터 너프 논란 / B보스 공략법 / 뉴비 세팅 추천"
   - 예시(좋음 - 스포츠갤): "김사자 타격폼 / 오늘 경기 감독 전술 / 9회말 오심 논란 / FA 영입 썰"
   - 예시(좋음 - 기기갤): "신형 폰 발열 이슈 / 노트북 배터리 타임 / 가성비 이어폰 추천 / A사 AS 후기"
   - 예시(나쁨): "최근 신규 패치에 대한 논의가 활발하며, 캐릭터 너프에 대한 불만이 있습니다." (친절한 문장형/보고서 형태 즉시 폐기)
