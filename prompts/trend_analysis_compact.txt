[작업]
위 원문에서 실제로 확인되는 소재만 짧게 정리한다. 추측, 새 사건, 특정 이용자 이야기, 게시판 운영 평가는 만들지 않는다.
민감한 표현·개인 공격·확인되지 않은 루머는 그대로 반복하지 말고 안전한 사물·장면·결과 중심의 말로 낮춘다.
초안은 만들지 않는다. 설명·마크다운 없이 JSON 객체 하나만 출력한다.

[필드 규칙]
- hot_topics: 현재 반복된 소재 1~3개
- sentiment: 한두 단어
- memes: 짧은 표현 0~3개
- topic_slots: 짧은 명사구 정확히 3개. 라벨, 번호, 대괄호, 줄바꿈을 절대 넣지 않는다.
- ai_analysis: 현재 소재와 반응 톤만 120~260자로 설명한다. 작문 지시는 쓰지 않는다.
- generation_guidance: 실제 제목의 구체 대상·장면·작은 사실 중 하나로 바로 참여하도록 1~2문장으로 쓴다. 없는 유행, 특정 인물, 민감 표현을 만들지 말라고 포함한다.

[출력 JSON]
{
  "hot_topics": ["..."],
  "sentiment": "...",
  "memes": [],
  "topic_slots": ["...", "...", "..."],
  "ai_analysis": "...",
  "generation_guidance": "..."
}
